# Hokii Poke
**Hokii Poke** 是一個提供顧客訂購夏威夷飯的電商網站，透過分類讓顧客依照喜愛項目挑選 Poke，進而加到購物車完成訂購。

> 現在就點擊進入 [Hokii Poke](https://huiwen-huang.github.io/vue-ecshop/#/) 來選購你的夏威夷飯吧！
